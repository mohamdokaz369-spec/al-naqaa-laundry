# قبل النشر

## مكتمل محليًا
- Supabase Auth بدل كلمة السر العامة ودخول الهاتف بدون تحقق.
- إنشاء رقم الطلب وسجل الحالات بقاعدة البيانات ضمن نفس المعاملة.
- منع التكرار بمفتاح UUID فريد، وتحديد المحاولات من قاعدة مشتركة.
- تحقق خدمة/هاتف/عنوان/إحداثيات/روابط/موعد على السيرفر.
- الدوام يوميًا 09:00–18:00 بتوقيت المغسلة.
- تصحيح تغيير السائق، تحديث البرنامج، أخطاء الموقع والحالة.
- واتساب الحقيقي، إزالة الأرقام التسويقية غير المثبتة.
- مبلغ نهائي وتحويل حالة التحصيل نقدًا من الإدارة.
- مخطط بداية، توثيق وCI واختبارات تراجع.

## يمنع الإطلاق حاليًا
- هوية قاعدة Supabase (تجربة أم إنتاج) غير مؤكدة حسب صاحب المشروع.
- تحقق اتصال المفتاح العام من لوحة المشروع ونجح عبر Auth settings ومكتبة التطبيق HTTP 200. لم يُختبر دخول مستخدم فعلي بعد. فحص OpenAPI السابق بطريقة Bearer ليس دليلًا على بطلان المفتاح.
- إضافات migrations 0002 و0003 غير موجودة في بنية القاعدة التي جرى فحصها قراءة فقط.
- migrations واختبارات SQL نجحت على PostgreSQL مؤقت باستخدام PGlite مع محاكاة أدوار Auth. لم تُختبر دورة الطلب أو تسجيل الدخول على Supabase فعلي.
- راجع grants وسياسات RLS الحالية، ثم طبق على staging واختبر قبل الإنتاج.

## خطوات التنفيذ
1. تحديد مشروع Supabase الصحيح ونسخة احتياطية، ومشروع staging منفصل.
2. مراجعة الجداول والأعمدة والسياسات بـ check_existing_policies.sql.
3. تطبيق migrations بالترتيب في staging. لا تعِد تشغيل migration قديم بعد الجديد.
4. إنشاء حساب إدارة وحسابي سائق، وربط profiles. تجربة حساب زائر وسائق معطل.
5. اختبار إنشاء متزامن بنفس Idempotency-Key، وسجل حالات ذري، ورفض الوصول غير المصرح.
6. اختبار الاستلام والتوصيل والتحصيل، بما فيها مبلغ صفر وعدم السماح بتحصيل بلا مبلغ.
7. ضبط البيئة على Vercel ومراجعة preview مع قاعدة staging؛ التنسيق بين ترحيل القاعدة ونشر الواجهة مطلوب.
8. تشغيل فحوص الكود والبناء والاختبارات، ثم مراجعة التغييرات قبل رفعها ونشرها.

## قرارات أو تكاملات لاحقة
- أسعار كل خدمة وسعر متر السجاد لم تُحدد؛ لا يوجد احتساب تلقائي للأسعار.
- الدفع الإلكتروني خارج النطاق الحالي: صاحب المشروع اختار نقدًا عند التسليم.
- واتساب الحالي روابط يدوية، والأتمتة تحتاج Meta WhatsApp Business ومزوّد وإعداد webhooks وقوالب.
- العبرية والمتاجر لم تنفذ. حسابات العملاء خارج نطاق الإطلاق حسب قرار المستخدم. Capacitor ومشاريع Android/iOS وتنبيهات الإدارة وموصلات Firebase/WhatsApp جهزت محليًا، لكن الأجهزة والخدمات الخارجية لم تختبر. راجع MOBILE_AND_NOTIFICATIONS.md.
- تقسيم صفحة الإدارة وتحسين تصميمها بصورة أوسع مؤجل بعد إثبات مسار التشغيل.
